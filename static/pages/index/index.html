hello, welcome to my site! nixwiz.network is my little corner on the internet that acts as a sort of bio where i host an assortment of random info, which you can find on the navbar to the left. the contents of this site and all other services found on any of my domains are hosted locally from a few spare computers in my room running gentoo. i use a vps from racknerd as a wireguard server for them so i can have a public IP address for my servers, letting everything become routable globally without having to deal with my ISP. the site you're seeing here is being served by an HTTP server sitting behind an nginx reverse proxy, with the static content served being arranged by a shell script. this website was written with pure HTML and CSS, and features no JavaScript content beyond the captcha. any server-sided functionality is handled by CGI shell scripts. this site's source code can be found at git.kitty.tel/nixwiz/nixwiz.network.
